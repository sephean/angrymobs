# 🐑 Angry Mobs

**Passive mobs fight back. Hit a sheep, and it hits you back.**

Tired of slaughtering chickens with no consequences? Not anymore.

With **Angry Mobs**, animals and other passive mobs defend themselves. Punch a cow and it charges at you instead of running away. And its friends come along to help.

## ⚔️ What changes

- **They fight back**: sheep, cows, pigs, chickens, horses, rabbits, villagers and other passive mobs attack whoever hits them.
- **No more running away**: no more panic, they stand their ground and fight.
- **They attack as a group**: hit one sheep and the whole flock comes after you.
- **They hurt**: 1.5 ❤ per hit, with knockback.
- Hostile and neutral mobs (wolves, iron golems, bees…) keep their vanilla behavior.

## 📦 Installation

- Minecraft **1.21.1**
- **Fabric Loader** 0.16+
- **Fabric API** required

Drop the jar into your `mods` folder. On a server, only the server needs the mod: players don't have to install anything.

## 🛠️ Building from source

Requires Java 21.

```bash
./gradlew build
```

The mod jar will be in `build/libs/`.
